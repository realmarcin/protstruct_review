Video tutorials with data

The data for each of these tutorials are available in the GUI by selecting 'New Project' and then 'Set up Tutorial Data' and selecting a tutorial. Each video tutorial provides some background and then carries out a demonstration using the tutorial data.

Help with tutorials from the Phenix chatbot

You can use the Phenix chatbot to get help on using any Phenix program. Just ask it any question about using Phenix.
