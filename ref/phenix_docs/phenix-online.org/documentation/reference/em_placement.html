Docking a model into a cryo-EM map with em_placement

Authors

  • Randy J Read, Claudia Millán, Airlie J McCoy, Thomas C Terwilliger

Purpose

The em_placement tool docks the input model in a cryo-EM reconstruction, using the half-maps in an adaptive search strategy.

How em_placement works

The half-maps are compared and analysed to determine signal and noise power as smooth functions in Fourier space. This information is used to predict whether or not a rotation search with a structural model over the full map volume is likely to succeed. If not, the maps are divided into sub-volumes small enough that the noise will be reduced to a level where signal from the rotation search can be detected. Following this, translation searches in the full map volume or the sub-volumes are carried out. Finally, rigid-body refinement is carried out using spherical sub-volumes centered on potential solutions to give the final solutions and confidence indicators.

A log-likelihood-gain (LLG) score greater than 60 suggests that a solution is significantly better than random.

NB: the statistical analysis requires the half-maps to correspond to the full volume of the cryo-EM reconstruction, so cut-out boxes cannot be used. Half-maps are required for a search over the whole reconstruction volume, whereas just a single full map can be used optionally for a search over a local volume.

Running em_placement

There is an EMplacement GUI to run em_placement, but it can also be controlled by an input script using the phil syntax. A basic phil script would look like the following, in which a model derived from the membrane domain of PDB entry 4cof is docked into the reconstruction of the GABA receptor in EMDB entry 11657.

em_placement
{
  remove_phasertng_folder = True

  map_model
  {
    half_map = emd_11657_half_map_1.map
    half_map = emd_11657_half_map_2.map
    best_resolution = 1.7
    point_group_symmetry = C5
    sequence_composition = 7a5v.fa
  }

  biological_unit {
    molecule
    {
      molecule_name = 4cofA_membrane
      model_file = 4cofA_membrane.pdb
      starting_model_vrms = 1.2
    }
  }

}

If the phil script is in a file named docking_script.phil, the search would be run from the command-line as follows.

phenix.voyager.em_placement docking_script.phil

Most parameters specified in this script have been named in a way intended to convey the purpose of that parameter.

The remove_phasertng_folder parameter is activated to clean up the graph database produced by phasertng, which could be used in other circumstances as part of a larger automation framework or for debugging.

If the point_group_symmetry is provided, the symmetry detected in the reconstruction is applied to generate a full assembly from a single copy.

The sequence_composition parameter specifies the name of a file containing the sequences of all the components in the reconstruction.

By default, em_placement carries out an adaptive search, which is normally recommended. Aspects of this search can be over-ridden with expert user keywords specified below, for example to force a full 6D search or to force only a single rotation search over the whole ordered volume regardless of the estimated signal.

List of all available keywords

  • em_placement
    • remove_phasertng_folder = True Removes the phasertng folder with the databases at the end of the run
    • level = process concise *summary logfile verbose testing Set the verbosity level
    • job_title = None Job title in PHENIX GUI, not used on command line
    • map_model
      • full_map = None Input full map file as alternative to half-maps
      • half_map = None Input half map files
      • point_group_symmetry = C1 Schonflies symbol plus order (e.g. D2, C7, I) or helical. Default is C1, no symmetry
      • best_resolution = None Best resolution (smallest d-spacing) found in input map. If zero it will be set automatically
      • cell_rescale = None Rescaling factor for map cell or magnification factor
      • sequence_composition = None Sequence file for entire EM reconstruction. Ignored if fixed_scattering_ratio is set, in which case total composition is set to model composition times fixed_scattering_ratio.
      • fixed_scattering_ratio = None If set, total composition is model composition times this factor
      • region_approach = *automatic manual rigid_body Method for specifying search regions
      • region_for_dockingManual specification for region(s)
        • name = None A name for the region
        • radius = None radius for the sphere for anisotropy correction and docking
        • center
          • x = None x coord center of sphere for docking search
          • y = None y coord center of sphere for docking search
          • z = None z coord center of sphere for docking search
    • docking
      • frf_rescoring = True use frfr after frf or not
      • frf_clustering = True use clustering or not for frf (or frfr if frf_rescoring)
      • frf_target_ellg = 225. ideal target eLLG for rotation search with strong signal
      • minimum_frf_ellg = 7.5 minimum target eLLG for rotation search: controls sub-volume size
      • refine_scale = False flag for whether or not to refine cell scale
      • top_files = 5 number of top potential solutions to save for output and focused docking
      • sigma_cut = 7. threshold for carrying out focused docking is top score - sigma_cut*sqrt(top score)
      • save_output_folder = True create output folder to save docked models and statistics
      • output_folder = None non-default path for output folder
      • brute_approach = *search six_dimensional_full six_dimensional_local search strategy (frf or brute)
      • angle_around
        • alpha = None alpha for brute rotation function angle
        • beta = None beta for brute rotation function angle
        • gamma = None gamma for brute rotation function angle
        • range = None angular range for brute rotation function
    • biological_unit
      • molecule
        • molecule_name = model A name for the search model
        • model_file = None Coordinate in .pdb or .cif
        • starting_model_vrms = 1.2 Starting RMSD estimate for the model
      • molecule_fixed
        • fixed_molecule_name = "fixed" A name for the fixed model
        • fixed_model_file = None Fixed model coordinates in .pdb or .cif
    • guiGUI-specific parameter required for output directory
      • output_dir = None
