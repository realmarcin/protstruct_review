Scaling unmerged anomalous data or multiple datasets with scale_and_merge

Author(s)

  • scale_and_merge: Tom Terwilliger

Purpose

scale_and_merge is a tool for scaling unmerged anomalous data or multiple data files and creating a scaled dataset and two scaled half-datasets. This tool normally is used in combination with anomalous_signal to create a scaled dataset and analyze anomalous signal in a SAD dataset. It can also be used to scale any other group of datasets.

Usage

How scale_and_merge works:

  • You supply scale_and_merge with a directory containing datafiles or the name of a single unmerged datafile.
  • You can optionally also specify a pair of labels that identifies datasets that are to be kept together. For example if you collected your data as pairs of datafiles with inverse beam geometry, you might have called the members of a pair data_1_0_w1.HKL and data_1_0_w2.HKL, related by w1 and w2.
  • scale_and_merge will first check the cell dimensions of all the datasets. Normally it will choose the largest set of similar crystals (you can have it keep all datasets with only_similar_datasets=False). It will also check the anisotropy in all the datafiles and calculate the average anisotropy (to be applied by default to all datafiles before scaling).
  • scale_and_merge will then scale all the data together. It will split your datafiles into smaller files if your datafiles contain duplicate measurements of the same indices. The intensities in each datafile will be adjusted for anisotropy to match the average anisotropy of all the datafiles. In this way all the datafiles are matched but the overall character of the data is not changed.
  • scale_and_merge will then scale each individual file with local scaling, producing files in the temporary directory with names ending in _scale.mtz. and then merge them all together.
  • Merging of the individual datasets is done twice, and then optionally two additional times to optimize anomalous differences.
  • In the first merging the individual datasets are simply averaged with weights based on the sigmas for each reflection. Then the individual datasets are compared with the overall mean dataset and dataset variances (estimates of systematic differences between datasets and the mean) are calculated based on the rms differences from the mean and the individual sigmas. In essence the dataset variance plus the individual variances are then to be used as estimates of the total variance for each reflection. The second merging uses these total variances in weighting rather than the original sigmas. The correlations of each individual dataset with the merged dataset are calculated.
  • If anomalous differences are optimized (default with optimize_anomalous=True), merging is carried out another time in order to optimize the weighting of anomalous differences in the merging step. For each unique reflection in the asymmetric unit of each dataset, the mean I+ and mean I- are used to calculate anomalous differences. The anomalous differences from each individual dataset are then compared with the anomalous differences from the merged dataset to estimate individual dataset anomalous difference variances. Then the anomalous differences from each individual dataset are averaged, with weights based on the original sigmas and the dataset variances. These merged anomalous differences are then used to replace the anomalous differences in the merged dataset above (for example, a reflection in the merged dataset above that has I+,sigI+,I-,sigI- would get new values of I+ and I- that have a difference equal to the appropriate merged anomalous difference, but the same mean as before.) The correlation of the anomalous differences in the original merged dataset and after optimization is printed (this should be high, for example 0.80).
  • The original datasets are then split into two parts for creation of two half-datasets. These half-datasets are useful for estimating the quality of the data and are used in anomalous_signal for this purpose.
  • The splitting into half-datasets is done in one of three ways, and the method is chosen based on the number of anomalous differences available for comparison using each method. With each method the data in each half-dataset are scaled just as the entire dataset was scaled. The preferred method is to split by files. Half of the datafiles are used to create each half-dataset. The next preferred method is to split with the first half of each dataset in one half-dataset and the second half in the other. The third preferred method is splitting alternate reflections with each unique index (after mapping to the asymmetric unit) into the two half-datasets. The last method is to randomly assign reflections to the two half-datasets. The reason for this hierarchical approach is that reflections measured close in time, within the same dataset are better matched than those measured further in time or within different datasets. These approaches for splitting the datafiles attempt to pair anomalous differences measured close in time and in the same dataset.
  • After half-datasets are obtained, the correlation of anomalous differences between half-datasets is estimated.

Possible Problems

Literature

List of all available keywords

  • input_files
    • data = None Anomalous data (I+ and I- or F+ and F-). Any standard format is fine. You can have any number of input files. If you have multiple files, specify the directory that contains them and nothing else.
    • data_labels = None Optional label specifying which columns of anomalous data to use. Not necessary if your input files have only one set of anomalous data. If you have multiple input files they need to have the same labels.
    • assume_shelx_observation_type_is = *amplitudes intensities For shelx files you need to specify if they are amplitudes or intensities
    • paired_group_ids = None Optional pair of identifiers that specify datasets that should be grouped together. The paired group ids must be the only characters that differ between datasets that should be grouped together, and the characters must uniquely define what datasets to group. For example paired_group_ids='w1 w2' would be the pair for the two datasets se_w1.sca and se_w2.sca. In this example you could also use paired_group_ids='w1.sca w2.sca' and that would have the same effect. Use this option when some of your datafiles are related to others by inverse-beam data collection for example. This matching of datasets can be very helpful.
    • check_file_type = False You can request that the data type of input files be checked if a data directory is supplied. Default is to read everything in the data directory.
    • reference_data = None Reference data for use in scaling. All datasets will be scaled to this reference dataset. Useful if you have very accurate native data.
    • reference_data_labels = None Optional label specifying which columns of reference data to use.
  • output_files
    • output_file = scaled_data.mtz Output data file name for merged scaled data
    • output_half_dataset_a = half_dataset_a.mtz Output data file name for half dataset A. Only written if get_half_datset_cc=True. This is the scaled merged data from half of the input data.
    • output_half_dataset_b = half_dataset_b.mtz Output data file name for half dataset B. Only written if get_half_datset_cc=True. This is the scaled merged data from the other half of the input data.
    • output_file_format = *mtz sca Output format for scaled data. Choices are MTZ and unmerged scalepack formats. Note: unmerged scalepack format not normally used because indices may be changed from original values and that data from within one input file may be merged, so that this unmerged data is partially merged and not the same as the original data.
  • crystal_info
    • resolution = None high-resolution limit
    • low_resolution = None Low-resolution limit
    • space_group = None Space group (normally read from the data file)
    • unit_cell = None Unit Cell (normally read from the data file)
  • data_selection
    • anomalous = True Consider data as anomalous (otherwise average Bijvoet mates).
    • minimum_datafile_fraction = 0.3 You can reject any datasets (after splitting) that have less than this fraction of the maximum number of reflections found in any datafile
    • require_fpfm = True If set, then when files are split into unique sets of indices only centric reflections and reflections with both F+ and F- present are written out. Note that in most space groups there may be more than one F+ or F- symmetry mate present. If any one is present for F+ and any one for F- the reflection is written out.
    • only_similar_datasets = True Group data by lattice similarity and take biggest group only. If space_group and unit_cell are set, then take those only that match this space_group and unit_cell. Use relative_length_tolerance and absolute_angle_tolerance to decide if two datasets are similar.
    • relative_length_tolerance = None Tolerance for considering two cells similar (fractional) You can allow anything with only_similar_datasets=False
    • resolution_length_tolerance = None Tolerance for considering two cells similar (fraction of resolution. For example normalized_length_tolerance=0.25 means the unit cells must match within 1/4 of the resolution. You can allow anything with only_similar_datasets=False
    • absolute_length_tolerance = None
    • absolute_angle_tolerance = None Tolerance for considering two cell angles similar (degrees) You can allow anything with only_similar_datasets=False
    • choose_optimal_datasets = False After initial merging, sort datasets by correlation to merged dataset, remove datasets until overall I/sigI is maximized, including dataset systematic errors in I/sigI.
    • sort_datasets_by_anomalous_cc = True For choosing optimal datasets, sort the datsets by anomalous CC. Alternative is sorting by non-anomalous CC.
  • scaling
    • make_anisotropy_uniform = True Calculate anisotropy for all datasets and adjust all of them to the average anisotropy. This is designed to improve scaling without changing the overall character of the data (i.e., not sharpening the data or removing anisotropy).
    • overallscale = False If set, only use overall scale and B (no local scaling)
    • skip_scaling = False You can skip the scaling step and just get half-dataset CC for a pair of existing files that you have put in a directory by themselves.
    • lowest_resolution_range = 6. Lowest value of the high-resolution cutoff for CC as a function of high-resolution cutoff with constant low-resolution cutoff
    • min_common_refl = 200 Minimum number of reflections in common to scale datasets
    • sort_on_batch_number = True You can sort XDS and MTZ reflections by frame number. Otherwise scale and merge assumes reflections are collected in the order in the data file.
    • scale_reference_data = True Scale reference data to maximum of 99999 if writing intermediate scalepack data files
  • merging
    • include_dataset_variance = True Scale datasets together including inter-dataset variance in in weighting. This takes into account the systematic differences among datasets and allows automatic down-weighting of datasets that are different than all the others.
    • optimize_anomalous = True Scale datasets together including inter-dataset variance in anomalous differences in weighting. Involves separation of mean intensity of each reflection from anomalous differences and recombination after scaling to recreate I+ and I-. Alternative is to include inter-dataset variance in intensities.
    • use_best_group_as_target = False Estimate inter-dataset variance by using the best dataset (highest I/sigma) as target for all datasets. This amounts to using all the other datasets to optimally estimate the data for this one crystal.
    • rescale_sigmas = False Rescale sigmas assuming that at high resolution, there are no anomalous differences. This can sometimes be useful if the sigmas are all too high or low and the data are collected to sufficiently high resolution that there really are essentially no anomalous differences (only noise) at high resolution.
  • half_dataset_cc
    • get_half_dataset_cc = True Split datasets and get half-dataset CC if data are available
    • half_dataset_cc_by_files = True Split datasets into groups based on keeping all data in a file together (only applies if multiple data files are supplied.)
    • half_dataset_cc_match_inverses = False Split datasets into groups keeping (hkl, -h-k-l) together. Applies if only one file or half_dataset_cc_by_files=False. Does not apply if less than half of the reflections have (-h-k-l) pairs and other methods below have more matches.
    • split_as_first_second_half = True split datasets into groups based on using the first or second half of each dataset in each half-dataset. Applies if half_dataset_cc_by_files=False or only one dataset is supplied and half_dataset_cc_match_inverses=False. Also applies if half_dataset_cc_by_files and half_dataset_cc_match_inverses have failed to yield sufficient anomalous differences.
    • split_alternately = True split datasets into groups based on sending observations of equivalent reflections alternately to the first or second half-dataset. Applies if split_as_first_second_half=False and half_dataset_cc_by_files=False and only one dataset is supplied. Also applies if other methods have failed to yield sufficient anomalous differences
    • split_randomly = True split datasets into groups based on sending observations of equivalent reflections randomly to the first or second half-dataset. Applies if split_as_first_second_half=False and half_dataset_cc_by_files=False and split_alternately is False and only one dataset is supplied. Also applies if other methods have failed to yield sufficient anomalous differences
  • directories
    • temp_dir = None Optional temporary work directory. If specified, it will be used for temporary files. If clean_up=True and it did not exist before, it will be removed at the end of the run. If it did exist, it will be left.
    • output_dir = "" Output directory where files are to be written
    • gui_output_dir = None GUI use only - does not apply to command line version
  • control
    • job_title = None Job title in PHENIX GUI, not used on command line
    • verbose = False Verbose output
    • random_seed = 714215 random seed
    • comparison_file = None Data file with comparison anomalous differences
    • multiprocessing = *multiprocessing sge lsf pbs condor pbspro slurm Choices are multiprocessing (single machine) or queuing systems
    • queue_run_command = None run command for queue jobs. For example qsub.
    • nproc = 1 Number of processors to use in scaling
    • solve_size = None You can set the size of Solve. Normally done automatically.
    • clean_up = True Clean up and remove temp directory after finishing
